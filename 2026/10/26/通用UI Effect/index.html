一、Default UI

UI Shader基础模板

一般的shader无法直接使用在UI上，需要在shader中定义特定的面板参数，且由于UI不受光照等因素的影响，需要关闭一些特殊通道。

[PerRendererData] ：将纹理值以MaterialPropertyBlock的形式从渲染器数据中获取，即unity会自动将 UI的Image自动和_MainTex对应。

_Stencil：模板测试相关属性，Unity会自动修改参数，UI可以使用模板测试进行不显示。
_ColorMask：设置颜色通道写入遮罩。写入 ColorMask 0 可关闭对所有颜色通道的渲染。
_UseUIAlphaClip是否用clip来进行不显示 。[Toggle(UNITY_UI_ALPHACLIP)], 如果Toggle是true , 则自动#define UNITY_UI_ALPHACLIP ,可以用#ifdef进行预处理。

二、Color Effect

GrayScale 置灰

置灰公式value=color.r x 0.299 +color.g x 0.587 + color.b * 0.114

Sepia 深褐色

用灰度图乘深褐色的颜色值即可。

Nega 反色

即图片的rgb各通道取反。

Pixel 像素化

对UV进行放大，然后再缩回原大小，导致UV精度丢失，形成马赛克效果。

Gradient渐变

将颜色值在某一方向上过渡，并与原纹理叠加。

Hue 色相

由于调整颜色时大部分调整的是hsv,我们需要将rgb值转换为hsv,调整色相(hue)、饱和度(saturation)和色调(value)，再转回rgb输出。

Blur 模糊

采样相邻像素点的颜色，与当前像素颜色按比例混合。

Dissolve 消融

采样消融纹理贴图并和基础纹理的a通道相乘即可。

Shiny 扫光

可以用贴图或代码得到扫光线，叠加在纹理贴图上，用_Factor控制扫光位置。

Glitch 故障

对r通道和b通道进行偏移，和在x轴上对uv进行偏移。

Hologram 全息

用代码或贴图得到黑白相间的纹理，在y轴上移动，再和颜色值相乘。

Shadow 阴影

在xy方向上做偏移多采样一次纹理，用阴影颜色进行填充，再与原纹理叠加。

Inline 内描边

从四个方向上偏移uv，并分别用于采样纹理贴图的a通道相乘,并做插值。

Outline 外描边

从四个方向上偏移uv，并分别用于采样纹理贴图的a通道，将得到的结果相加，最后用原纹理覆盖。

Innerline 描线

在图像的边缘处，灰度值相差越大，将得到的插值与描线颜色相乘，再与原纹理做叠加。

Outlighting 外发光

对图像四个方向进行偏移，根据for循环控制从内部到边缘的不透明度不断减小。

三、UV Effect

Zoom 缩放

直接乘。

Rotate 旋转

先将uv移动到（0，0）点，乘以旋转矩阵，再移动回原来位置。

uv旋转算法

Shake 震动

uv坐标加上sin值，_ShakeUvSpeed控制震动速度。

Distortion 扰动

采样扰动贴图，在xy方向上用_DistortTexXSpeed控制扰动速度，最后uv坐标加上扰动值。

Twist 扭转

旋转纹理UV坐标，越靠近中心旋转角度越大，越往外越小。

Wave 波浪

在x或y方向上加上sin值。

四、Mix

在实际应用中可以将以上几种不同的效果混合在一起，可以构成各式各样的特殊效果。
